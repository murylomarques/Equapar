# Autorização de publicação de caso (modelo)

> Modelo revisado e aprovado pelo advogado em 25/11/2026. Este texto é só para o dono; nenhuma tela do sistema o usa. Mudança no texto pede nova revisão.

A [contratante], por [representante autorizado], autoriza a Equapar a publicar o caso do contrato [identificador autorizado] com [nome empresarial ou anonimização], [marca, se autorizada], [descrição aprovada] e [valor efetivamente recebido, comprovado em data]. A autorização vale para [canais] até [prazo] e se limita à versão aprovada por escrito. A contratante pode solicitar a retirada futura pelo canal [e-mail]. O material divulgado deve excluir dados de empregados e informações protegidas pelo contrato.
